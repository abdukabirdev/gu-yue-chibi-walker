# Chibi Walker

Чиби-маскот для Chrome, который живёт на всех сайтах: гуляет, прыгает по элементам страницы, лазает по стенам, летает, когда его бросают, читает сайт и (по желанию) отвечает через Gemini или Claude.

## Установка

1. **[⬇ Скачать chibi-walker.zip](https://github.com/abdukabirdev/gu-yue-chibi-walker/releases/latest/download/chibi-walker.zip)** (последний релиз).
2. Распакуй архив — получится папка `chibi-walker`.
3. Открой `chrome://extensions` и включи **«Режим разработчика»** (переключатель справа вверху).
4. Нажми **«Загрузить распакованное расширение»** и выбери папку `chibi-walker` (ту, где лежит `manifest.json`).
5. Перезагрузи открытые вкладки — маскот появится на странице.

### Обновление

1. Скачай новый zip по той же ссылке и замени файлы в старой папке.
2. В `chrome://extensions` нажми ↻ у «Chibi Walker».
3. Перезагрузи открытые вкладки.

### Установка из исходников

```bash
git clone https://github.com/abdukabirdev/gu-yue-chibi-walker.git
```

Дальше — шаги 3–5 выше, указав папку клона.

## Нейросеть (необязательно)

Ключ Gemini или Claude вводится во всплывающем окне расширения. Ключ хранится только в `chrome.storage` браузера и отправляется лишь на API выбранного провайдера.
